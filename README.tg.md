# Scetch — барномаи Flutter барои аз рӯйи намуна расм кашидан бо камера

[English](README.md) | [Русский](README.ru.md) | **Тоҷикӣ**

Scetch барномаи **camera tracing барои Android ва iOS** мебошад, ки бо Flutter сохта шудааст. Аксро интихоб кунед, онро ба тарҳ ё хатҳои контурӣ табдил диҳед ва тасвири намунаро болои намоиши зиндаи камера ҷойгир кунед, то дар рӯйи коғаз расм кашед. Шаффофият, ҷойгиршавӣ, андоза ва гардишро танзим карда, намунаро қулф кунед.

Ҳисоби корбар, сервер ва таҳлили рафтори корбарон вуҷуд надоранд. Тасвирҳо дар дастгоҳи шумо мемонанд. Намуна дар экран ҷойгир мешавад; барнома мавқеи онро дар муҳити воқеӣ тавассути AR пайгирӣ намекунад. Марҳилаи 2 ба доираи кунунии лоиҳа дохил намешавад.

**Вазъи лоиҳа:** рамзи манбаъии марҳилаи 1 навишта шудааст, аммо омодагӣ ба истифодаи истеҳсолӣ **ҳанӯз тасдиқ нашудааст**. Тавлиди рамзи Freezed/Drift, тасвирҳои меъёрии golden, таҳлили Flutter, санҷишҳо ва сохтани барномаҳои Android/iOS бояд иҷро шаванд. Натиҷаҳо ва маҳдудиятҳо дар [VALIDATION.md](VALIDATION.md) сабт шудаанд.

## Имкониятҳо

- Интихоби акс тавассути равзанаи системавӣ ва ислоҳи самти EXIF.
- Буридан, гардондан, оинавӣ кардан ва барқарор кардани тасвир.
- Омодасозии намуна дар ҳолатҳои Original, Grayscale, High Contrast, Outline ва Sketch.
- Танзими равшанӣ, контраст, ҳамворкунӣ, ҷузъиёт, қувваи канорҳо ва ғафсии хат.
- Ҷойгир кардани намуна болои камера бо танзими шаффофият, ҷойивазкунӣ, калонкунӣ бо ду ангушт, гардиш ва инъикос аз ду меҳвар.
- Қулф кардани намуна ва кушодани қулф бо нигоҳ доштани тугма.
- Шабакаи хатҳои роҳнамо, ки ба экран ё намуна пайваст мешавад, ва муқоисаи навбатии камера/намуна — blink.
- Танзими калонкунии камера, фокус, экспозитсия ва чароғак, агар дастгоҳ онҳоро дастгирӣ кунад.
- Нигоҳ доштани лоиҳаҳо дар Drift/SQLite ва боз кардани онҳо баъдтар.
- Мавзӯи равшан, торик ё мувофиқ ба танзими система.

## Талабот

- **Flutter 3.47.4 stable / Dart 3.13.3** — версияҳое, ки аз рӯйхати расмии нашрҳо дар 13 сентябри 2026 интихоб шудаанд.
- **Android:** JDK 17, Android SDK ва дастгоҳи API 24 ё навтар. Версияҳои compile/target SDK аз ҷониби Flutter муайян мешаванд.
- **iOS:** macOS, Xcode-и мувофиқ бо Flutter ва CocoaPods. Ҳадди ақал iOS 13.0. Дар Windows сохтани барномаи iOS имкон надорад.
- Дастгоҳи воқеӣ барои санҷидани камера, чароғак, иҷозатҳо ва суръати кор.

Манбаъҳо: [бойгонии Flutter SDK](https://docs.flutter.dev/install/archive), [camera](https://pub.dev/packages/camera), [image_picker](https://pub.dev/packages/image_picker), [ҳуҷҷатҳои Drift](https://drift.simonbinder.eu/).

## Оғози кор

```sh
flutter --version
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

Freezed, табдили JSON ва Drift ба рамзи тавлидшуда ниёз доранд. Пас аз тағйир додани моделҳо ё ҷадвалҳои пойгоҳи додаҳо build_runner-ро иҷро кунед. Баъд аз бомуваффақият насб шудани вобастагиҳо `pubspec.lock`-ро ба репозиторий илова кунед. Пеш аз нашр навсозии вобастагиҳоро санҷед.

Агар Gradle wrapper ҳанӯз аз ҷониби абзорҳои Flutter сохта нашуда бошад:

```sh
flutter create --empty --platforms=android,ios --org com.scetch --project-name scetch --no-pub .
```

Парчами `--overwrite`-ро илова накунед: танзимоти махфият ва иҷозатҳои платформаҳо аллакай дар репозиторий ҳастанд.

## Танзими Android

Android SDK ва JDK-ро насб карда, `flutter doctor -v` ва `flutter doctor --android-licenses`-ро иҷро кунед. Flutter файли `android/local.properties`-ро месозад; ин файли вобаста ба компютер ба репозиторий илова намешавад.

```sh
flutter build apk --debug
flutter run -d <device-id>
```

Пеш аз паҳн кардани барнома имзои release-ро бо keystore-и худ танзим кунед. Барнома дастрасӣ ба камераро мепурсад; аксҳо тавассути равзанаи системавӣ интихоб мешаванд. Дар манифести release иҷозати INTERNET нест. Он дар debug/profile барои абзорҳои Flutter истифода мешавад. Нусхабардории абрӣ ва интиқоли маълумоти барнома байни дастгоҳҳо дар танзимот манъ шудаанд.

## Танзими iOS

```sh
flutter pub get
cd ios
pod install
cd ..
flutter build ios --no-codesign
open ios/Runner.xcworkspace
```

Дар Xcode bundle identifier ва гурӯҳи имзогузории худро интихоб кунед. Тавсифи сабаби дастрасӣ ба камера ва китобхонаи аксҳо, танзими scene lifecycle ва `PERMISSION_CAMERA=1` илова шудаанд. Сабти садо хомӯш аст ва дастрасӣ ба микрофон дархост намешавад.

AppDelegate ҷузвдони Application Support-ро аз нусхабардории iCloud хориҷ мекунад. Манифести махфияти барнома ҷамъоварии маълумотро эълон намекунад. Пеш аз нашр манифестҳои required-reason API-и вобастагиҳоро дар бойгонии сохташуда санҷед.

## Тарзи расмкашӣ

1. Барои интихоби акс **New Drawing** ё **Import From Gallery**-ро пахш кунед.
2. Ҳудудҳои уфуқӣ ва амудии буриданро танзим кунед; сипас тасвирро гардонед, оинавӣ кунед ё ба ҳолати аввал баргардонед.
3. **Image Preparation**-ро кушода, Original, Grayscale, High Contrast, Outline ё Sketch-ро интихоб кунед. Outline ва Sketch хатҳоро дар заминаи шаффоф месозанд. Танзимоти details, edge strength ва line width барои ҳамин ду ҳолат дастрасанд.
4. **Start tracing**-ро пахш кунед. Намунаро ҷойиваз кунед, бо ду ангушт калон ё хурд кунед ва гардонед. Барои гузоштани нуқтаи фокус/экспозитсия ба намоиши камера ду бор зарба занед, агар камера ин амалро дастгирӣ кунад.
5. Шаффофият, инъикоси уфуқӣ/амудӣ, марказкунӣ, ҷойгиркунӣ дар экран, reset, шабака, blink, чароғак, калонкунии камера ва экспозитсияро танзим кунед.
6. **Lock reference** абзорҳои асосиро пинҳон карда, тағйири ҷойгиршавии намуна ва шабакаро манъ мекунад. Барои кушодани қулф тугмаро нигоҳ доред. Амали системавии «Бозгашт» низ аввал кушодани қулфро талаб мекунад.

Телефонро дар пояи устувор болои коғаз маҳкам кунед. Ба экран нигоҳ карда, бо даст расм кашед.

Тағйироти ҷойгиршавӣ баъд аз таваққуфи 300 мс, ҳангоми ба замина гузаштани барнома ва ҳангоми баромадан нигоҳ дошта мешаванд. Агар сабт нашуда бошад, тугмаи Retry нишон дода мешавад; баромадан аз экран сабти муваффақро талаб мекунад. Recent Projects ва Projects лоиҳаҳоро аз SQLite барқарор мекунанд.

## Меъморӣ

Лоиҳа аз рӯйи хусусиятҳо ҷудо шудааст: моделҳои тағйирнопазири Freezed, Riverpod 3, go_router, плагинҳои расмии camera/image_picker ва Drift/SQLite истифода мешаванд.

| Ҷузвдон | Вазифа |
|---|---|
| `lib/app` | Оғози барнома, пайваст кардани вобастагиҳои Riverpod, роҳҳо ва мавзӯъҳо |
| `lib/core` | Камера, координатаҳо, коркарди тасвир, файлҳо, Drift, иҷозатҳо, хатоҳо, сабти рӯйдодҳо ва ҳудуди кэш |
| `lib/features` | Home, лоиҳаҳо, воридоти акс, муҳаррир, расмкашӣ, танзимот ва шиносоии аввал |
| `lib/shared/widgets` | Абзорҳои умумии интерфейс ва нишон додани хатоҳо |

Қабатҳои data/domain/presentation дар ҷойҳое истифода мешаванд, ки вазифаи мушаххас доранд. Барои экранҳои статикӣ қабатҳои холии repository ё use-case сохта нашудаанд.

- **Нигоҳдории маълумот:** repository нигоҳдории лоиҳаҳоро аз интерфейс ҷудо мекунад. Drift схемаи версиядор ва ҳолати лоиҳаро дар JSON нигоҳ медорад; тасвирҳо файлҳои алоҳидаанд. Роҳҳо нисбат ба Application Support сабт мешаванд, то тағйири роҳи мутлақи sandbox дар iOS лоиҳаҳоро вайрон накунад.
- **Коркарди тасвир:** `ImageProcessor` шартномаи ивазшавандаи коркард аст. Марҳилаи 1 бастаи Dart `image`-ро дар isolate истифода мебарад. OpenCV пайваст нашудааст ва интерфейс онро ворид намекунад; адаптери native метавонад ҳамин шартномаро татбиқ кунад.
- **Хотира:** рамзкушоӣ, ислоҳи EXIF, буридан, филтрҳо ва рамзгузорӣ дар isolate иҷро мешаванд. Пеш аз филтрҳо тарафи дарозтарини тасвир то 1600 px кам карда мешавад. Ҳудуди вуруд 40 MiB ва 48 MP аст. Рамзкушоии пурраи асл ҳанӯз хотира талаб мекунад ва бояд дар заифтарин дастгоҳи ҳадаф санҷида шавад.
- **Кэш:** кэши тасвирҳои коркардшуда то 96 MiB ва кэши тасвирҳои рамзкушоишудаи Flutter то 64 MiB маҳдуд аст. Тасвирҳои сабтшуда ба ҷузвдони лоиҳа нусхабардорӣ мешаванд. Пешнамоишҳои кӯҳна баъд аз сабти версияи нав тоза мешаванд.
- **Табдилҳо:** `TraceTransform` матритсаи ягона барои ҷойгиркунӣ, андоза, гардиш, инъикос ва ҷойивазкунии нормалишуда дорад. Нуқтаи такягоҳи имову ишора нуқтаи интихобшудаи намунаро зери ангуштон нигоҳ медорад.
- **Координатаҳо:** `CameraCoordinateMapper` cover/contain, гардиши сенсор/дастгоҳ, инъикоси камераи пеш ва пикселҳои ҷисмонӣ/мантиқиро ба ҳисоб мегирад. CameraPreview ва фокус геометрияи якхелаи буриданро истифода мебаранд. Ин намунаи экранӣ аст, на пайгирии фазоӣ бо AR; телефон бояд беҳаракат бошад.
- **Давраи ҳаёти камера:** `CameraSession` амалҳои native ва озодкунии захираҳоро пайдарпай иҷро мекунад. Generation token намегузорад, ки контроллери кӯҳна баъд аз баромадан аз экран ба интерфейс дода шавад.
- **Blink:** AnimationController/FadeTransition шаффофияти намоишро иваз мекунад; ҳангоми ҳар ивазшавӣ layout ва рамзкушоии тасвир такрор намешаванд.
- **Махфият:** сабтҳои техникии муфассал танҳо берун аз release фаъоланд. Тасвирҳо ва номҳои воридкардаи корбар ба хидматҳои беруна фиристода намешаванд.

## Санҷиш ва тасдиқ

```sh
dart format lib test integration_test
flutter analyze --fatal-infos
flutter test --coverage
flutter test integration_test -d <device-id>
flutter build apk --debug
# Танҳо дар macOS:
flutter build ios --no-codesign
```

PowerShell: `./tool/verify.ps1`. Unix/macOS: `bash tool/verify.sh` ё `bash tool/verify.sh ios`.

Рамзи санҷишҳо табдилҳо, нуқтаи такягоҳ, координатаҳо, шаффофият, ҳолати қулф, танзимоти JSON, коркарди тасвир, кэш ва барқарорсозии SQLite баъд аз бастани пойгоҳро фаро мегирад. Санҷиши давраи ҳаёти камера баромадан ҳангоми initialization-ро модел мекунад. Санҷишҳои widget абзорҳо ва қулфро месанҷанд; golden барои Home-и равшан/торик ва шабакаи намуна пешбинӣ шудааст. Санҷиши integration дар дастгоҳ аз шиносоии аввал, Home, Projects ва Settings мегузарад. Ин санҷишҳои Flutter дар муҳити сабтшуда ҳанӯз иҷро нашудаанд.

Тасвирҳои меъёрии golden-ро дар версияҳои муайяни Flutter ва системаи амалиётӣ сохта, бо чашм санҷед:

```sh
flutter test --tags golden --update-goldens
flutter test --tags golden
```

Тасвирҳои меъёриро дар CI худкор нав накунед. То пайдо шудани меъёри тасдиқшуда `--exclude-tags golden` барои ташхиси санҷишҳои дигар кӯмак мекунад, аммо маънои гузаштани санҷиши пурраро надорад.

`python tool/verify_structure.py` XML/plist/assets, пайвандҳои Xcode, воридоти нисбии Dart ва танзимоти шабака/нусхабардории Android release-ро месанҷад. Ин санҷиши статикӣ аст, на сохтани барномаи native.

**Натиҷаи сабтшуда:** рамз бо WASM-порти dart_style формат карда шуд, парсер хатои синтаксисӣ наёфт ва сохтори native санҷида шуд. Таҳлили Flutter, тавлиди рамз, санҷишҳо ва сохтани барнома ҳанӯз тасдиқ нашудаанд, зеро SDK дар муҳити дастрас насб нашуд. Тасвирҳои golden ва файлҳои тавлидшудаи Freezed/Drift ҳанӯз мавҷуд нестанд. Тафсилот: [VALIDATION.md](VALIDATION.md) (ба русӣ).

## Санҷиш дар дастгоҳ пеш аз нашр

- Иҷозатро диҳед, рад кунед ё доимӣ рад кунед; аз Settings баргардед.
- Экрани расмкаширо зуд кушоед/пӯшед; ҳангоми дархости иҷозат ва initialization барномаро ба замина гузаронед; бозгаштро такрор кунед.
- Самтҳои амудӣ/уфуқӣ, камераи қафо бо сенсори 90°/270°, таносубҳои гуногуни экран ва матни калонро санҷед.
- Телефонро маҳкам кунед; фокусро дар канорҳои намоиши буридашуда ва рафтори намуна ҳангоми гардиш, калонкунӣ ва инъикос санҷед.
- Баъд аз таҳрир, қулф ва тағйири шабака/шаффофият барномаро аз нав оғоз карда, лоиҳаи барқароршударо муқоиса кунед.
- JPEG-и 12/48 MP бо EXIF, PNG/WebP, файли вайрон, камбуди ҷой ва қатъ шудани picker дар Android-ро санҷед.
- Дар заифтарин дастгоҳи ҳадаф бо Flutter DevTools frame chart, p95 frame time, хотира ва 20 дақиқаи tracing/blink-ро чен кунед. **60 FPS ҳадафи қабул аст, на натиҷаи ченшуда.**

## Ҳалли мушкилот

| Мушкилот | Амали пешниҳодшуда |
|---|---|
| `Target of URI hasn't been generated` | build_runner-ро иҷро кунед. |
| `Camera permission required` | Retry ё Open Settings-ро интихоб кунед. Маҳдудияти назорати волидайн берун аз барнома тағйир дода мешавад. |
| `Camera unavailable` | Барномаҳои дигари камераро пӯшед ва дастгоҳи воқеиро истифода баред. |
| `Unsupported format` | JPEG, PNG ё WebP интихоб кунед. Коркардгари Dart HEIC-ро мустақим дастгирӣ намекунад; агар picker онро табдил надода бошад, JPEG содир кунед. |
| `Processing failed` | Файли хурдтарро санҷед ва ҷойи холиро тафтиш кунед. |
| Санҷишҳо дар Windows оғоз намешаванд | Боргирии test engine-и Flutter ва китобхонаи native-и SQLite-ро ҳангоми насби SDK/бастаҳо тафтиш кунед. |
| Мушкилоти CocoaPods | Дар macOS баъд аз `flutter pub get` иҷро карда, `.xcworkspace`-ро кушоед. |

Ҳангоми нест кардани барнома лоиҳаҳои маҳаллӣ ҳам нест мешаванд. Содирот ва ҳамоҳангсозӣ ба марҳилаи 1 дохил намешаванд.
